# その雨、大丈夫ですか？ — 大雨・台風から命を守る 防災LP

大和冷機労働組合の組合員とご家族向けの防災啓発ランディングページです。
ゲリラ雷雨・豪雨・台風・河川氾濫・内水氾濫・土砂災害・道路冠水から、
**「危険が迫ったとき、具体的に何をすればいいのか」** を短時間で伝えることを目的としています。

## ファイル構成

```
bousai-lp/
├── index.html        … ページ本体（アイコンはSVGスプライトとして内蔵）
├── css/
│   └── style.css     … スタイル（スマホファースト／外部依存なし）
├── js/
│   └── main.js       … 目次メニュー・チェックリスト・共有ボタン・表示アニメーション
├── images/           … イラスト（SVG）と組合ロゴ
│   ├── hero.svg        ファーストビュー（家族と雨雲・雷）
│   ├── river.svg       河川の近く
│   ├── coast.svg       海岸・低地
│   ├── landslide.svg   崖・山の近く（土砂災害）
│   ├── underpass.svg   冠水したアンダーパス
│   ├── supplies.svg    防災用品（家族4人分のイメージ）
│   ├── family.svg      家族会議
│   ├── union-logo.webp 組合ロゴ（ヘッダー・ファーストビュー・組合メッセージ・フッターで使用）
│   └── favicon.svg     ファビコン
└── README.md
```

- フレームワーク・外部CDN・Webフォントは使っていません。
- `index.html` をダブルクリックで開くだけで表示確認できます（共有ボタンのみ、公開後のURLで動作します）。

## 表示確認

1. `index.html` をブラウザで開く。
2. スマホ表示は、ブラウザの開発者ツール（Chrome: F12 → デバイスツールバー）で確認できます。

## GitHub Pages で公開する

1. GitHub で新しいリポジトリを作成（例：`bousai-lp`）。
2. このフォルダの中身（`index.html` / `css` / `js` / `images` / `README.md`）をリポジトリ直下にアップロード。
3. リポジトリの **Settings → Pages** で、Source を `Deploy from a branch`、Branch を `main` / `/(root)` に設定して保存。
4. 数分後に `https://<ユーザー名>.github.io/bousai-lp/` で公開されます。

Netlify・Cloudflare Pages・社内Webサーバーなど、静的ファイルを置ける場所ならどこでも同じ構成で公開できます。

## 主な機能

| 機能 | 内容 |
|---|---|
| 固定ヘッダー | 「キキクルを見る」ボタン（黄色）と目次ボタンを常に表示。PC幅（1100px以上）では目次を横並びで常時表示 |
| 目次 | 8項目へアンカーリンクでジャンプ。Escキー・背景タップで閉じる |
| キキクルボタン | ヘッダー・ファーストビュー・「最新情報」セクションの3か所に配置 |
| 自宅周辺チェック | チェックすると該当数を表示し、ハザードマップボタンを強調 |
| 家族チェックリスト | チェック状態をその端末のブラウザ（localStorage）にだけ保存。保存できない環境でも表示は正常 |
| 共有ボタン | 対応端末では Web Share API（LINE・メール等へ共有）。非対応端末では「LINEで送る」「URLをコピー」を表示 |
| アニメーション | 雨の背景とスクロール時のフェードイン。OSの「視差効果を減らす」設定時は停止 |

## アクセシビリティ

- 見出し構造（h1→h2→h3）、`lang="ja"`、本文へのスキップリンク
- すべてのイラストに内容を説明する `alt`、装飾アイコンは `aria-hidden`
- 外部リンクは新しいタブで開くことをスクリーンリーダー向けに明示
- ボタン・リンクはタップ領域 44px 以上、キーボード操作時のフォーカス表示あり
- 文字色と背景色はコントラスト比に配慮（本文は 4.5:1 以上を目安）

## 情報の正確性について

- 警戒レベルの表は、**2026年5月28日に運用が始まった気象庁の「新たな防災気象情報」**（レベル4「危険警報」の新設、警報・注意報名へのレベル表記）と、内閣府の避難情報（レベル3 高齢者等避難／レベル4 避難指示／レベル5 緊急安全確保）に基づいています。
- 車の水没時の脱出、雷、土砂災害の前兆などは、気象庁・内閣府・国土交通省・JAFが公表している一般的な内容の範囲で記載しています。
- 制度は変更されることがあります。**公開前・毎年の出水期前（5月頃）に、上記の公的機関のページで最新情報を確認**してください。
- ページ下部に「一般的な防災情報であり、実際の災害時は公的機関・自治体の最新情報と指示に従う」旨の注意書きを掲載しています。

## カスタマイズのヒント

- **組合名**：`index.html` 内の「大和冷機労働組合」を検索して変更。ロゴは `images/union-logo.webp` を差し替え。
- **色**：`css/style.css` 冒頭の `:root` の変数（`--navy-800`, `--blue-500`, `--yellow`, `--orange`, `--red` など）を変更。
- **イラスト差し替え**：`images/` 内のSVGを同じファイル名で置き換えるか、`index.html` の `<img src>` を変更（PNG/JPG/WebPも可）。差し替えたら `alt` の説明文も更新してください。
- **SNS用サムネイル**：LINE等で共有したときに画像を出す場合は、1200×630px の PNG/JPG を `images/ogp.png` として用意し、`<head>` に以下を追加してください（URLは公開先の絶対URL）。
  ```html
  <meta property="og:image" content="https://<公開URL>/images/ogp.png">
  <meta property="og:url" content="https://<公開URL>/">
  ```
